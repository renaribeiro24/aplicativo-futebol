# Primitivas shadcn/ui

Componentes `button`, `card`, `badge`, `input`, `skeleton` e `alert` incorporados da fonte oficial `shadcn-ui/ui`, diretório `apps/v4/registry/new-york-v4/ui`, consultado em 19/10/2026:

https://github.com/shadcn-ui/ui/tree/main/apps/v4/registry/new-york-v4/ui

O registro do CLI shadcn não respondeu neste ambiente. A incorporação usou os arquivos oficiais do GitHub, sem gerador alternativo. Alterações locais: import de cn direcionado a @/lib/utils, Slot direcionado a @radix-ui/react-slot e formatação Prettier. A licença MIT original está em LICENSE.md. components.json mantém os aliases para futuras adições pelo CLI fixado nas devDependencies.

Esses componentes são fontes editáveis, não um pacote fechado. Tokens globais estão em src/app/globals.css. O lockfile fixa suas dependências.
